Guía de ejecución – A* Planner con ROS 2

Este documento explica los pasos necesarios para compilar y ejecutar la simulación del robot junto con el planificador A* y la localización mediante AMCL.

Pasos a seguir

  1. Acceder al workspace de ROS: cd /home/alba/rosbot_ws/
  2. Compilar el workspace: colcon build
  3. Lanzar la simulación en Gazebo: ros2 launch rosbot_gazebo simulation.launch.py robot_model:=rosbot
  4. Publicar el mapa: ros2 run controldesc_pkg map_publisher.py --ros-args -p map_yaml:=/home/[tu usuario]/rosbot_ws/controldesc_pkg/src/A_star_controller/maps/husarion_world.yaml

    ⚠️ Sustituye [tu usuario] por tu nombre de usuario.

  5. Ejecutar el nodo del planificador A*: ros2 run controldesc_pkg A_star_mejor.py
  6. Lanzar AMCL: ros2 launch controldesc_pkg amcl_launch.py
  7. Activar el lifecycle de AMCL: ros2 lifecycle set /amcl activate
  8. Ejecutar el controlador del robot: ros2 run controldesc_pkg robot_controller.py
  9. Configurar RViz:
    • Fixed Frame: map
    • Add → By topic:
      • /map
      • /laser_scan
      • /astar_path
  10. Para que el mapa se visualice correctamente en RViz:
    • En Map → Topic
    • Configurar Durability Policy como: Transient Local

Resultado esperado

Una vez completados todos los pasos correctamente, el robot deberá:

  • Localizarse en el mapa usando AMCL
  • Calcular un camino mediante el algoritmo A*
  • Mostrar el mapa, el láser y el path en RViz
  • Seguir el camino generado
