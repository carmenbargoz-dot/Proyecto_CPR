Compilación del entorno

Antes de poder lanzar el sistema, es necesario compilar los paquetes. Desde la raíz del espacio de trabajo (rosbot_ws), ejecute:

colcon build

Instrucciones para lanzar el sistema

Primero configurar el entorno de la terminal antes de trabajar con el sistema. Una vez compilado, desde el directorio rosbot_ws ejecutar:

source install/setup.bash

Tras esto se declaran las instrucciones para lanzar el sistema.

Terminal 1

Configurar el sistema y todo lo relacionado con él:

ros2 launch controldesc_pkg sistema.launch.py escenario:= planificador:=

Argumentos

Escenario (mundo deseado para lanzar)

Posibilidades:

  • custom
  • husarion_office
  • husarion_office_completo
  • husarion_world
  • laberinto
  • laberinto_complejo
  • obstaculos
  • obstaculos2

Planificador (tipo de planificación deseada para la trayectoria)

Posibilidades:

  • Astar
  • Theta
  • Theta2

Ejecución para los archivos de evaluación

Archivos del control

El control genera en el directorio rosbot_ws/ unos archivos .txt donde se guardan la trayectoria original, real y suavizada, estos deberán trasladarse a rosbot_ws/graficas/control/, una vez hecho esto, ejecutar:

python3 grafica_control.py

Archivos de planificación

Para graficar los archivos .txt generados por el planificador, tanto para la comparación de factores entre mundos graficas_comp_factor.m como para la comparación de algoritmos graficas.m:

  • Declarar el nombre de los resultados que se desean estudiar en el archivo .m
  • Abrir Octave
  • Ejecutar el archivo .m deseado
