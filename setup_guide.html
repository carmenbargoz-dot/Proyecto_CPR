🤖 Guía de Configuración y Uso de ROSbot en Simulación

📂 Directorio de Trabajo

cd /home/alba/rosbot_ws/

🚀 1. Lanzar Simulación

Archivos Modificados:

📄 simulation.launch.py
  • Añadido soporte para argumento gz_world
  • Añadidos argumentos de posición: x, y, z
  • Valores por defecto: x=0.0, y=0.0, z=0.2
  • Mundo por defecto: husarion_world.sdf

Comando de Lanzamiento:

ros2 launch rosbot_gazebo simulation.launch.py robot_model:=rosbot gz_world:=$(ros2 pkg prefix husarion_gz_worlds)/share/husarion_gz_worlds/worlds/husarion_office.sdf
💡 Nota: El mundo husarion_office.sdf ha sido modificado:
  • ✅ Eliminados 3 robots decorativos
  • ✅ Eliminadas papeleras, ordenadores y sillas
  • ✅ Eliminadas ~60% de las mesas
  • ✅ Eliminados ~48% de los cajones
  • ✅ Añadida pared conectora personalizada

Alternativas de Mundos:

Mundo básico (por defecto):
ros2 launch rosbot_gazebo simulation.launch.py
Mundo vacío:
ros2 launch rosbot_gazebo simulation.launch.py gz_world:=$(ros2 pkg prefix husarion_gz_worlds)/share/husarion_gz_worlds/worlds/empty_with_plugins.sdf

Cambiar Posición Inicial:

ros2 launch rosbot_gazebo simulation.launch.py x:=2.0 y:=3.0 z:=0.2

🗺️ 2. SLAM - Creación de Mapas

Archivo de Configuración:

📄 /home/alba/slam/slam_toolbox.yaml

Lanzar SLAM Toolbox:

ros2 launch slam_toolbox online_async_launch.py slam_params_file:=/home/alba/slam/slam_toolbox.yaml
💡 Consejo: Asegúrate de que la simulación esté corriendo antes de lanzar SLAM.

💾 3. Guardar Mapa Creado

Comando para Guardar:

ros2 run nav2_map_server map_saver_cli -f ~/robot_ws/controldesc_pkg/src/A_star_controller/maps/nom_mapa
⚠️ Importante:
  • Reemplaza nom_mapa con el nombre deseado para tu mapa
  • Se generarán dos archivos: nom_mapa.pgm y nom_mapa.yaml
  • Asegúrate de que el directorio de destino existe

Ejemplo:

ros2 run nav2_map_server map_saver_cli -f ~/robot_ws/controldesc_pkg/src/A_star_controller/maps/oficina_mapa

🔧 Workflow Completo

Paso 1: Compilar el workspace
cd /home/alba/rosbot_ws/ colcon build --symlink-install source install/setup.bash
Paso 2: Lanzar simulación
ros2 launch rosbot_gazebo simulation.launch.py robot_model:=rosbot gz_world:=$(ros2 pkg prefix husarion_gz_worlds)/share/husarion_gz_worlds/worlds/husarion_office.sdf
Paso 3: En otra terminal, lanzar SLAM
source /home/alba/rosbot_ws/install/setup.bash ros2 launch slam_toolbox online_async_launch.py slam_params_file:=/home/alba/slam/slam_toolbox.yaml
Paso 4: Teleoperar el robot para mapear
# El teleoperador ya está incluido en la simulación # Usa el joystick o teclado para mover el robot
Paso 5: Guardar el mapa
ros2 run nav2_map_server map_saver_cli -f ~/robot_ws/controldesc_pkg/src/A_star_controller/maps/mi_mapa

  • husarion_office.sdf - Limpieza del mundo (robots, mesas, sillas, etc.)

Características del Mundo Modificado:

  • ✅ Sin robots decorativos en mesas

  • ✅ Pared personalizada para delimitar área
  • ✅ Archivo reducido de 8797 a ~3200 líneas

✅ Verificación

Para verificar que todo funciona correctamente:

  1. La simulación de Gazebo debe abrirse con el mundo de oficina
  2. RViz debe mostrar el robot y los sensores
  3. SLAM Toolbox debe empezar a crear el mapa mientras mueves el robot
  4. El mapa se guarda correctamente en el directorio especificado
