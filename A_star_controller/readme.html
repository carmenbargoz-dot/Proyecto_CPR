README — Lanzar A* planner (ROS2 Humble)

Pasos y comandos para detener procesos antiguos, publicar el mapa, iniciar el planificador, abrir RViz y probar un goal.

1) Parar procesos antiguos

pkill -f map_publisher.py || true
pkill -f A_star.py || true
pkill -f rviz2 || true
pkill -f map_server || true

2) Source ROS 2 y workspace

source /opt/ros/humble/setup.bash
source ~/rosbot_ws/install/setup.bash || true

3) Lanzar publicador de mapa (Terminal A)

python3 ~/rosbot_ws/src/husarion_controllers/A_star_controller/map_publisher.py

4) Lanzar A* planner (Terminal B)

python3 ~/rosbot_ws/src/husarion_controllers/A_star_controller/A_star.py

5) Abrir RViz2 (Terminal C)

rviz2

En RViz: Fixed Frame = map. Añade displays: Map (topic /map, borra Update Topic), y RobotModel.

6) Establecer pose inicial (opcional)

python3 ~/rosbot_ws/src/husarion_controllers/A_star_controller/set_initial_pose.py --x X --y Y --yaw YAW

Ejemplo: --x -0.278 --y -0.185 --yaw 0.0

7) Publicar un goal (Terminal D o RViz)

ros2 topic pub /goal_pose geometry_msgs/PoseStamped "{header: {frame_id: 'map'}, pose: {position: {x: 0.5, y: 0.0, z: 0.0}, orientation: {w: 1.0}}}"

O usar la herramienta 2D Goal en RViz (confirma el topic; suele ser /goal_pose o /move_base_simple/goal).

Mostrar el path A* en RViz

  1. En RViz añade el display Path.
  2. Configura el Topic a /astar_path y el Fixed Frame a map.
  3. Ajusta Color y Width (p.ej. verde y 0.08) para mayor visibilidad.
  4. Activa Axes o Pose si quieres ver cada punto.

8) Comprobaciones

ros2 topic info /map
ros2 topic echo /map --once
ros2 topic echo /amcl_pose --once
ros2 topic echo /astar_path --once
ros2 node list
Nota: mantén map_publisher.py corriendo antes de iniciar A_star.py para recibir el mapa latcheado (QoS TRANSIENT_LOCAL).

Si el mapa no aparece al abrir RViz

Si el display Map queda vacío, sigue estos pasos rápidos:

  1. Detén el publicador: 
    pkill -f map_publisher.py || true
  2. Vuelve a lanzar el publicador (desde el workspace): 
    source /opt/ros/humble/setup.bash
python3 ~/rosbot_ws/src/husarion_controllers/A_star_controller/map_publisher.py
    3. Comprueba info.width, info.height y info.resolution.

Opciones adicionales

  • Si RViz publica el goal en otro topic, ajusta goal_topic del nodo A* o remapea el topic.
  • Si el mapa tiene huecos, considera el post-procesado (parámetros YAML: dilate_radius, close_gaps).
